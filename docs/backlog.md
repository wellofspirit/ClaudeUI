## Claude Desktop host-side features worth borrowing

From Anthropic's Desktop docs and the Desktop 2.42304.0 host bundle (research notes in
`docs/research/session-tools/`, untracked). The session tools themselves are the session-tools arc
(`docs/session-tools-handoff.md`).

| Feature                                | What it does                                                                                                                                                                                               |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Local scheduled tasks                  | Named task (prompt, model, permission mode, folder, worktree) on a schedule; a fresh session per run; one catch-up run for the latest miss; per-task always-allowed rules; the task can reschedule itself. |
| Keep computer awake                    | Sleep inhibitor while sessions work or tasks are due.                                                                                                                                                      |
| Preview / browser pane                 | Dev servers from `.claude/launch.json` (name, command, args, port, cwd, env); embedded browser; Claude checks its work after edits (screenshots, DOM, clicks, console).                                    |
| PR monitoring                          | CI status chip; auto-fix failing CI and review comments; optional auto-merge (via `gh`).                                                                                                                   |
| Diff review comments                   | Per-line comments on the diff, submitted together as one prompt.                                                                                                                                           |
| Auto-archive on PR merge/close         | Finished local sessions archive themselves when their PR merges or closes.                                                                                                                                 |
| Needs-you notifications                | OS/push notification when a session finishes or blocks while not viewed, saying what Claude needs (`post_turn_summary.needs_action`).                                                                      |
| Dispatch                               | Message a task from the phone; it starts a session on the desktop machine.                                                                                                                                 |
| Chapters                               | `mark_chapter`: transcript dividers + floating table of contents for long sessions.                                                                                                                        |
| Side chats                             | `/btw`-style side question that reads the thread and writes nothing back.                                                                                                                                  |
| Dual-pane sessions                     | Two live sessions side by side.                                                                                                                                                                            |
| Integrated terminal / file editor pane | Terminal in the session cwd; editable file pane with on-disk change warning.                                                                                                                               |
| iOS simulator / Android emulator panes | Device stream + input, triggered by Claude Code's `dev_intent: ios_app`. macOS only.                                                                                                                       |
| Computer use                           | Screen + input control with per-app tiers.                                                                                                                                                                 |
